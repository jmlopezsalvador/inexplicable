# Plantilla KMP (Android + iOS)

Cómo usarla para un proyecto nuevo:
1. Copia esta carpeta entera con otro nombre (p. ej. `MiNuevaApp`) y ábrela con Claude Code.
2. Escribe cualquier cosa (p. ej. «empecemos»): `CLAUDE.md` le indica a Claude que debe inicializar el proyecto
   (preguntarte nombre, paquete y funcionalidad, renombrar la plantilla y crear `docs/SPEC.md`).
3. Tus cosas sueltas van en `ignore/` (Claude no las mira). Referencias para la app, en `data/`.
